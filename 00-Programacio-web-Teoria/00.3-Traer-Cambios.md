# 00.3 - Traer cambios de GitHub 

Cuando trabajamos en **otra computadora** o hicimos cambios directamente en GitHub, necesitamos actualizar nuestra carpeta local.

## Traer los últimos cambios

Primero abrimos la terminal dentro de nuestro proyecto.

```bash
git pull origin main
```

Este comando:

* Busca los últimos cambios en GitHub.
* Los descarga.
* Actualiza nuestra carpeta local.

---

## Ejemplo

Supongamos que trabajaste en tu casa y subiste cambios a GitHub.

Al día siguiente abrís el proyecto en otra computadora.

Antes de empezar a trabajar ejecutá:

```bash
git pull origin main
```

Ahora tu proyecto tendrá la versión más reciente.

---

## ⚠️ Importante

Antes de comenzar a programar, acostumbrate a ejecutar:

```bash
git pull origin main
```

Así evitás trabajar sobre una versión vieja del proyecto.

---

## 🔄 Flujo recomendado

### Antes de trabajar

```bash
git pull origin main
```

### Después de trabajar

```bash
git status
git add .
git commit -m "Descripción de los cambios"
git push origin main
```

---

> 💡 **Regla fácil:**
> **PULL** → Traer cambios de GitHub.
> **PUSH** → Subir cambios a GitHub.
