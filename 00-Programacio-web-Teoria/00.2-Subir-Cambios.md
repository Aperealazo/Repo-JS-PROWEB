# Subir cambios a GitHub

Cada vez que terminemos un ejercicio o hagamos cambios importantes podemos subirlos a GitHub.

## Paso 1 - Revisar cambios

```bash
git status
```

## Paso 2 - Preparar archivos

```bash
git add .
```

## Paso 3 - Crear el commit

```bash
git commit -m "Descripción de los cambios"
```

Ejemplo:

```bash
git commit -m "Agrego ejercicios de operadores"
```

## Paso 4 - Subir a GitHub

```bash
git push origin main
```

---

# Resumen

Los comandos habituales son:

```bash
git status
git add .
git commit -m "Descripción"
git push origin main
```

> No utilizar siempre mensajes como `"cambios"` o `"actualizacion"`.
> Intentá describir brevemente qué hiciste.
