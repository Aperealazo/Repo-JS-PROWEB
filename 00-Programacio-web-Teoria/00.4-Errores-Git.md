# Solución de errores de Git

Antes de llamar al profesor, buscar el error en esta guía.

---

## Error: `Author identity unknown`

Git no conoce tu nombre o correo.

```bash
git config --global user.name "Nombre Apellido"
git config --global user.email "correo@gmail.com"
```

Después volver a realizar el commit.

---

## Error: `not a git repository`

Estás parado en una carpeta que no es un repositorio Git.

Verificá dónde estás y entrá a la carpeta correcta del proyecto.

Después:

```bash
git status
```

---

## Error: `nothing to commit`

No hay cambios nuevos para guardar.

Comprobar:

```bash
git status
```

Si aparece:

```text
nothing to commit, working tree clean
```

No hay nada nuevo para subir.

---

## Error: `repository not found`

Primero revisar:

```bash
git remote -v
```

Comprobar que aparezca **TU usuario y TU repositorio de GitHub**.

Si está incorrecto:

```bash
git remote set-url origin https://github.com/USUARIO/REPOSITORIO.git
```

---

## Error: `remote origin already exists`

El repositorio remoto ya está configurado.

NO volver a ejecutar:

```bash
git remote add origin
```

Revisar primero:

```bash
git remote -v
```

---

## Error: `rejected` o `non-fast-forward`

GitHub tiene cambios que tu computadora todavía no tiene.

Ejecutar:

```bash
git pull origin main
```

Luego:

```bash
git push origin main
```

---

## Error: `src refspec main does not match any`

Puede faltar el primer commit.

```bash
git add .
git commit -m "Primer commit"
git branch -M main
git push -u origin main
```

---

# ¿Estoy usando el repositorio correcto?

Ejecutar:

```bash
git remote -v
```

Tiene que aparecer tu repositorio.

Ejemplo:

```text
origin  https://github.com/juanperez/programacion.git
```

---

# ¿Estoy en la rama correcta?

```bash
git branch
```

Debería aparecer:

```text
* main
```

Si aparece `master`:

```bash
git branch -M main
```

---

# ¿La computadora tiene la cuenta de otro alumno?

IMPORTANTE:

```bash
git config --global user.name
git config --global user.email
```

permite comprobar quién figura como autor de los commits.

Pero esto **no necesariamente indica qué cuenta de GitHub está autenticada**.

En Windows, si quedó iniciada la cuenta de otro alumno, probar:

```bash
git credential-manager github logout
```

Luego:

```bash
git push
```

Volver a iniciar sesión con tu cuenta de GitHub.

---

# Diagnóstico

Si nada de lo anterior funciona, ejecutar:

```bash
git status
git branch
git remote -v
git config --global user.name
git config --global user.email
```

## Si no funciona nada de nada... :/

Dejá la terminal abierta y mostrá:

1. El error completo.
2. El resultado de `git status`.
3. El resultado de `git remote -v`.

**No decir solamente:** "Profe, Git no anda".

**Mostrar el error que aparece en la terminal.**
