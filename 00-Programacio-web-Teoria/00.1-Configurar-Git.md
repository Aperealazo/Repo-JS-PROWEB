# Configuración inicial de Git

Esta configuración se realiza normalmente **una sola vez por computadora**.

## 1. Configurar nombre

```bash
git config --global user.name "Nombre Apellido"
```

Ejemplo:

```bash
git config --global user.name "Juan Perez"
``` 

## 2. Configurar correo

Utilizar preferentemente el mismo correo asociado a GitHub.

```bash
git config --global user.email "correo@gmail.com"
```

Ejemplo:

```bash
git config --global user.email "juanperez@gmail.com"
```

## 3. Comprobar

```bash
git config --global user.name
git config --global user.email
```

Los datos que aparecen deben ser los tuyos.

---

## Ver toda la configuración

```bash
git config --global --list
```

> Si aparece el nombre o correo de otro alumno, volver a realizar los pasos anteriores con tus datos.
