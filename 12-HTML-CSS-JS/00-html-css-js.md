# HTML, CSS y JavaScript

En esta clase vamos a crear una página web sencilla utilizando:

- HTML.
- CSS.
- JavaScript.
- Inteligencia Artificial.

El objetivo es comprender qué función cumple cada tecnología.

---

## HTML

HTML crea la estructura y el contenido de una página.

Permite agregar:

- Títulos.
- Párrafos.
- Imágenes.
- Botones.
- Enlaces.
- Formularios.

Ejemplo:

```html
<h1>Mi página web</h1>
<p>Esta es mi primera página.</p>
<button>Presionar</button>
```

---

## CSS

CSS controla la apariencia de la página.

Permite modificar:

- Colores.
- Tamaños.
- Tipografías.
- Fondos.
- Bordes.
- Espacios.

Ejemplo:

```css
button {
    background-color: blue;
    color: white;
}
```

---

## JavaScript

JavaScript agrega comportamiento e interacción.

Permite:

- Mostrar mensajes.
- Pedir información.
- Realizar cálculos.
- Responder cuando se presiona un botón.

Ejemplo:

```js
function saludar() {
    alert("¡Hola desde JavaScript!");
}
```

---

## Cómo trabajan juntos

Podemos pensar una página como una casa:

- HTML construye la casa.
- CSS pinta y decora la casa.
- JavaScript hace funcionar las puertas y las luces.

---

# Actividad

Crear una tarjeta sobre un tema que ustedes elijan.

Puede ser sobre:

- Un futbolista.
- Un animal.
- Un videojuego.
- Una película.
- Un personaje.
- Un artista.
- Un equipo.

## Cambios obligatorios

Modificar en `index.html`:

1. El título de la página.
2. El nombre de la tarjeta.
3. La descripción.
4. Los tres datos.
5. El texto del botón.

Modificar en `script.js`:

1. La pregunta realizada al usuario.
2. El mensaje que aparece al final.

---

# Utilización de Inteligencia Artificial

El diseño CSS podrá generarse con ayuda de una IA.

Antes de solicitar el código deben decidir:

- El tema.
- Los colores.
- El tipo de diseño.
- La sensación que quieren transmitir.

## Prompt sugerido

```text
Actuá como diseñador web.

Tengo una tarjeta creada con HTML sobre [ESCRIBIR TEMA].

Necesito que generes solamente el código para mi archivo estilos.css.

Quiero un diseño [MODERNO, DEPORTIVO, ELEGANTE O DIVERTIDO].

Los colores principales deben ser [ESCRIBIR COLORES].

El diseño debe incluir:

- Fondo para la página.
- Tarjeta centrada.
- Bordes redondeados.
- Sombra suave.
- Botón con efecto al pasar el mouse.
- Diseño adaptable a celulares.

No modifiques el HTML ni agregues JavaScript.
Explicá brevemente qué parte del CSS controla cada elemento.
```

También pueden buscar inspiración en:

- https://uiverse.io/
- https://cssgradient.io/
- https://coolors.co/
- https://fonts.google.com/

## Reglas

- No copiar y pegar sin revisar.
- Mantener separados HTML, CSS y JavaScript.
- Modificar como mínimo cinco propiedades del CSS.
- Poder explicar qué hace cada archivo.
