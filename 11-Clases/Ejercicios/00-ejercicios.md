# Ejercicios — Clases en JavaScript

## Ejercicio 1 — Animales

Crear una clase llamada `Animal`.

Cada animal deberá tener:

- Nombre.
- Especie.
- Edad.

Crear **3 animales diferentes** utilizando la clase.

Mostrar los datos de cada animal en la consola.

---

## Ejercicio 2 — Alumnos

Crear una clase llamada `Alumno`.

Cada alumno deberá tener:

- Nombre.
- Apellido.
- Curso.
- Nota.

Crear **3 alumnos diferentes**.

La clase deberá tener un método que permita mostrar la información completa de cada alumno.

---

## Ejercicio 3 — Estado del alumno

Utilizando la clase `Alumno` del ejercicio anterior, agregar un método que determine si el alumno está:

- **APROBADO** si su nota es mayor o igual a 6.
- **DESAPROBADO** si su nota es menor a 6.

Probar el funcionamiento con diferentes alumnos y notas.

---

## Ejercicio 4 — Mascota virtual

Crear una clase llamada `Mascota`.

Cada mascota tendrá:

- Nombre.
- Tipo de animal.
- Energía.

Todas las mascotas comenzarán con **5 puntos de energía**.

La mascota podrá realizar dos acciones:

- **Jugar:** pierde 1 punto de energía.
- **Comer:** recupera 1 punto de energía.

Crear una mascota y realizar varias acciones.

Al finalizar, mostrar cuánta energía tiene.

---

# Desafío

Crear una clase sobre un tema que ustedes elijan.

Puede representar un videojuego, vehículo, personaje, película, equipo, producto u otra idea.

## Requisitos

La clase debe tener como mínimo:

- 4 atributos.
- 2 métodos.
- 3 objetos creados a partir de la clase.

Los objetos deben tener datos diferentes.

> No alcanza con que el código funcione. Deben poder explicar qué hace la clase, qué representa cada objeto y para qué utilizan `this`.
