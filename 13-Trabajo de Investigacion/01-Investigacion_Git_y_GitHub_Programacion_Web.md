## Propósito de la actividad

Esta actividad propone investigar qué son **Git y GitHub**, cómo se relacionan y por qué se utilizan para guardar, organizar y compartir proyectos de programación.

El trabajo finalizará con una presentación grupal y una aplicación de los conceptos al proyecto realizado en la carpeta `12-HTML-CSS-JS`.

## Pregunta central

> ¿GitHub es solamente un lugar para guardar código o también es una herramienta para organizar y desarrollar proyectos en equipo?

## Modalidad y entrega

- Trabajo grupal de **2 o 3 integrantes**.
- Presentación de **7 a 10 diapositivas**.
- Exposición oral de **5 a 7 minutos**.
- Todos los integrantes deberán participar de la explicación.

### 4. Conceptos fundamentales

Investigar y explicar:

- Repositorio.
- Commit.
- Rama o branch.
- Push.

Incluyan un ejemplo propio para cada concepto.

### 5. Flujo básico de trabajo

Explicar el siguiente proceso:

1. Crear o modificar archivos.
2. Revisar los cambios realizados.
3. Preparar los archivos.
4. Crear un commit.
5. Subir los cambios a GitHub.

### 6. Comandos esenciales

Los siguientes comandos deben aparecer en la presentación y ser explicados con palabras propias:

| Comando | Función |
|---|---|
| `git init` | Inicia un repositorio Git en la carpeta actual. |
| `git status` | Muestra el estado de los archivos y los cambios pendientes. |
| `git add .` | Prepara todos los cambios para incluirlos en el próximo commit. |
| `git commit -m "mensaje"` | Guarda una versión de los cambios con una descripción breve. |
| `git push` | Envía los commits locales al repositorio remoto en GitHub. |
| `git pull` | Descarga e integra cambios del repositorio remoto. |
| `git clone URL` | Copia un repositorio existente en la computadora. |

También deberán indicar **en qué momento del trabajo se utiliza cada comando**.

### 7. Trabajo colaborativo

### 8. Ventajas y dificultades

Investigar las ventajas y posibles dificultades de utilizar Git y GitHub:

- Recuperar versiones anteriores.
- Guardar proyectos en línea.
- Compartir código.
- Organizar cambios.
- Errores frecuentes al comenzar.

### 9. Ejemplo práctico

Deberán mencionar:

### 10. Conclusión

Responder con sus propias palabras:

> ¿Por qué un estudiante de Programación Web debería aprender Git y GitHub?
